# 📊 Superstore Sales Dashboard

![Dashboard Preview](dashboard.png)

An interactive **business intelligence dashboard** built using **Python, Streamlit, and Plotly** to analyze sales, profit, and customer behavior.

---

## 🎯 Project Overview

This dashboard provides a complete analytical view of a retail superstore dataset, helping businesses:

- Track key performance metrics
- Understand sales trends
- Analyze profitability
- Identify high-performing regions and categories

---

## 🚀 Features

- 📊 **KPI Metrics**
  - Total Sales
  - Total Profit
  - Total Orders
  - Quantity Sold

- 📈 **Monthly Sales Trend**
  - Identifies seasonal demand patterns

- 🍩 **Sales by Category**
  - Contribution of each product category

- 📉 **Discount vs Profit Analysis**
  - Shows impact of discounts on profitability

- 🗺️ **Geographical Sales Map (USA)**
  - State-wise sales performance

- 📅 **Year-wise Comparison**
  - Growth trends over time

- 🏆 **Top Products Analysis**
  - Best-performing products by sales

---

## 📈 Key Insights

- 📌 Sales peak during **November–December** (strong seasonal demand)
- 📌 Higher discounts tend to **reduce profitability**
- 📌 **Technology category** contributes the highest revenue
- 📌 **California and New York** dominate sales
